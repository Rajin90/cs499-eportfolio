Source for my CS 499 Computer Science Capstone ePortfolio (Southern New Hampshire University), published with GitHub Pages.

Open `index.html` to start. The site presents my professional self-assessment first, followed by my CS 360 Inventory Management Android application, enhanced in three categories: software design and engineering, algorithms and data structures, and databases.
