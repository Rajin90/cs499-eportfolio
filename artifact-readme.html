How to run

  1. Android Studio → File → Open → select Enhanced/MyDatabaseApp. Let Gradle sync.
  2. Run on an emulator (Android 8.0 / API 26 or newer).
  3. Unit tests: right-click app/src/test → Run Tests, or run gradlew test.
  4. Performance timings: open Logcat and filter by the tag CS499_DB_PERF.

If the emulator still has the old version of the app installed, the new version upgrades its database automatically (version 1 → 2) and keeps the existing items and accounts.
